Design a modern responsive web application UI for an e-pharmacy platform.

Concept:
A smart online pharmacy system that allows users to find nearby pharmacies, search for medicines, and order health packs for chronic diseases.

Target Users:
General users, including elderly people → must be simple, accessible, and easy to use.

Style:

* Clean, modern, and professional (inspired by health-tech startups)
* Minimalist layout with smooth spacing
* Rounded corners and soft shadows
* Card-based UI

Color Palette (IMPORTANT – must follow strictly):

* Primary: #0F766E (Dark Teal Green)
* Secondary: #2F8F7E (Teal Green)
* Accent: #5FA79A (Soft Teal)
* Light Background: #8FB9B0 (Light Teal)
* Very Light Background: #B7D1CC (Mint Green)

Usage:

* Use #0F766E for main buttons and primary actions
* Use #2F8F7E for secondary buttons and highlights
* Use #5FA79A for cards, hover states, and UI accents
* Use #8FB9B0 and #B7D1CC for backgrounds and sections
* White for main content areas
* Dark gray text for readability

Typography:

* Clean sans-serif (like Inter / Poppins)
* Large readable text (accessibility friendly)

Layout:

* 12-column grid system
* Responsive design (Desktop first, then tablet/mobile)

Pages to design:

1. Landing Page:

* Hero section with CTA (Find Medicine)
* Features section:

  * Nearby pharmacies
  * Medicine search
  * Health packs
* Clean footer

2. Authentication:

* Login / Sign up (centered card layout)

3. Dashboard:

* Top navbar (logo, search, profile)
* Sidebar:

  * Home
  * Pharmacies
  * Medicines
  * Health Packs
  * Orders
  * Profile
* Main:

  * Search bar
  * Nearby pharmacies (cards)
  * Health packs (cards)

4. Pharmacy Map:

* Full map layout
* Teal-colored pins
* Info card (name, distance, open/closed, call button)

5. Medicine Search:

* Filters (price, availability)
* Results with cards

6. Health Packs:

* Grid cards:

  * Diabetes Pack
  * Asthma Pack
* Highlight cards using teal gradients

7. Order Page:

* Cart UI
* Total price
* Confirm button (Primary color)

8. Profile:

* User info
* Orders history
* Settings

UX Requirements:

* Very simple navigation
* Clear call-to-action buttons
* Large clickable areas
* Smooth hover effects using teal shades

Extras:

* Medical and location icons
* Subtle gradients using teal palette
* Soft shadows for depth
* Loading and empty states

Goal:
Create a professional, startup-level UI using a cohesive teal-based color system.
